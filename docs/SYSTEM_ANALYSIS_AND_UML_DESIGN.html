1. المقدمة ونظرة عامة على النظام

يمثل نظام إدارة وتتبع الأعطال التقنية حلاً مؤسسياً متكاملاً لأتمتة ورصد بلاغات الدعم الفني والصيانة للأجهزة، البرمجيات، الشبكات، والأنظمة داخل المؤسسات والجامعات. يوفر النظام بيئة عمل تشاركية تربط بين أربعة أطراف رئيسية (المستخدمين، الفنيين، المشرفين، ومديري النظام) لضمان حوكمة العمل وسرعة إنجاز المهام وفق معايير جودة الخدمة (SLA).

التذاكر الذكية المتكاملة

تسجيل بلاغ العطل مع تحديد الموقع والأولوية وتصنيف العطل ورفع المرفقات والصور بسهولة.

محادثة لحظية لكل تذكرة

غرفة دردشة مباشرة مرفقة بكل بلاغ لتبادل الإيضاحات والصور بين الفني والمستخدم والإدارة.

تنبيهات فورية متعددة القنوات

إشعارات داخلية فورية وتنبيهات بريد إلكتروني آلية في كل مرحلة من مراحل البلاغ.

تحليلات وتقارير احترافية

لوحات تحكم تفاعلية مع إمكانية التصدير إلى وثائق PDF رسمية وكشوفات Excel إحصائية.

2. تحليل المتطلبات الوظيفية وغير الوظيفية

2.1 المتطلبات الوظيفية (Functional Requirements)

  • إدارة الحسابات والمصادقة: التسجيل، تسجيل الدخول الآمن، استعادة كلمة المرور عبر كود OTP بريدي، وإدارة الملف الشخصي.
  • دورة حياة بلاغات الصيانة: إنشاء البلاغ، مراجعته، تعيين الفني المختص، جدولة التاريخ، بدء المعالجة، تدوين تقرير الحل، وتقييم الجودة.
  • نظام المحادثة والرسائل: إرسال واستقبال الرسائل والصور داخل التذكرة مع تتبع حالة القراءة.
  • الإشعارات والبريد: تنبيه الأطراف المعنية لحظياً عند إضافة بلاغ، إسناده، حله، أو التقييم.
  • التقارير والإحصائيات: استخراج جداول Excel المنسقة وتوليد ملفات PDF متقدمة عبر ReportLab.

2.2 المتطلبات غير الوظيفية (Non-Functional Requirements)

  • الأمان والخصوصية: تشفير كلمات المرور باستخدام Bcrypt، تفعيل الحماية من CSRF، وتعقيم كافة استعلامات SQL.
  • الأداء والاعتمادية: سرعة استجابة فائقة واستخدام قواعد بيانات سحابية موثوقة (PostgreSQL على Supabase).
  • التوافقية والتدويل: دعم اللغتين العربية (RTL) والإنجليزية (LTR) مع توافق تام لكافة المتصفحات والأجهزة المحمولة.

دعم ثنائي للغتين (AR / EN)

التبديل الفوري بين اللغة العربية مع محاذاة RTL واللغة الإنجليزية مع محاذاة LTR بنقرة زر واحدة.

7. التحصين وهيكلية الأمان السيبراني

  • تشفير Bcrypt: تشفير كلمات المرور باستخدام خوارزمية التجزئة التكيفية المقاومة لهجمات القوة الغاشمة.
  • حماية CSRF الصارمة: تضمين توكن أمان مشفر ديناميكي في كافة النماذج عبر `Flask-WTF`.
  • منع هجمات SQL Injection: تمرير كافة المدخلات باستخدام الاستعلامات البارامترية المعقمة في مكتبة `psycopg2`.
  • حماية رفع الملفات: التحقق من الامتدادات المسموح بها واستخدام `secure_filename` وتحديد سقف الحجم بـ 16 ميجابايت.
  • أمان الجلسات: تعيين ملفات تعريف الارتباط بخاصية `HttpOnly` و `SameSite=Lax` مع ترويسات منع الكاش `No-Cache`.
